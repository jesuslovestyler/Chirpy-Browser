Chirpy Engine 0.23 — the finishing set test

Every effect on this page is drawn with CSS alone. Read down and check each numbered promise. Two honest notes before the promises: Chirpy answers media questions when a page loads, so the width promise below asks you to resize and reload; and hover here is paint, never layout — a hover may change colors and underlines, and it may never move a word.

This line carries the same slant rule, and a font: shorthand that never mentions slant at all. The shorthand resets what it does not mention, so this line should stand UPRIGHT, in Georgia, at 17px — the slant is gone, not inherited from the rule beside it.

5 — @media: the window's width

This box answers (max-width: 750px). In a wide window it wears pale blue. Narrow the window below 750 points and RELOAD the page — the box should wear pale red instead. Widen it again and reload, and the blue returns. Chirpy answers media questions as the page loads, with the width of the window's text area as it stood when the load began, so the reload is part of the promise.

6 — @media: the system's own answers

This box follows prefers-color-scheme, as it has since the variable step: pale in a light Mac, dark in a dark one. The finishing set kept the promise while widening the questions around it.

This box answers prefers-reduced-motion. If your Mac's Reduce Motion accessibility setting is on, the box wears pale green; if it is off, the box stays gray. Either way the page has truly asked the system — open System Settings, Accessibility, Display to see which answer yours gives.
