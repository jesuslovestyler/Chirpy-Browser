Chirpy Engine 0.30 — flexbox test

Every arrangement on this page is made with CSS flexbox alone. Read down and check each numbered promise. First, the status line at the bottom of the window should read "Chirpy Engine 0.30.0 (Swift)". Two honest notes before the promises: the items on this page are paint, not live text — the floated boxes' bargain since 0.17 — so a link inside an item shows its colors but does not click; and since 0.30, wrap-reverse and align-content are read too — promises 12 and 13 below are theirs, and promise 14 is the container's own percentage height.

1 — space-between

FIRST — I hug the left edge of the yellow bar.
MIDDLE — I stand exactly halfway between the other two.
LAST — I hug the right edge. The yellow showing between us is the leftover space, shared evenly into the two gaps.

2 — flex-grow takes the leftover

FIXED — 140 points wide, as declared.
GROWING — I have flex-grow: 1, so every point of leftover width between the two fixed boxes is mine: I stretch to fill it, however wide the window stands, and the green box is pushed to the right edge. If I am only as wide as my words, grow has failed.
FIXED — 140 points wide, as declared.

SHRINK 3 — but this row is set only 480 wide, so we each give back a third of the overflow and stand about 150 wide, side by side inside the 480, instead of spilling past it.

The cross axis is flipped: the lines stack upward from the bar's bottom edge, so the first line in file order is the lowest one on the page.

14 — a percentage height against a definite one

HALF — this yellow bar is height: 50% inside the pale step around it, which declares 300: the bar stands half the step's inside height, and the pale ground shows the other half below it.

And where no ancestor declares a height, a percentage height still reads as the content's own height — every other bar on this page is the proof, standing exactly as tall as what it holds.

End of the test page. If all fourteen promises held, flexbox works.
