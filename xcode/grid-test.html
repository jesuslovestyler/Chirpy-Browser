Chirpy Engine 0.25 — grid test

Every arrangement on this page is made with CSS grid alone. Read down and check each numbered promise. First, the status line at the bottom of the window should read "Chirpy Engine 0.25.0 (Swift)". Honest notes before the promises: the items on this page are paint, not live text — the floated boxes' bargain since 0.17 — so a link inside an item shows its colors but does not click; grid-auto-flow: column is not read yet (its pages get row flow), and neither is dense packing — the placement cursor never backs up into a hole it passed; named lines and grid-template-areas are parsed past, not placed by; baseline alignment of items reads as start; and a grid container's percentage height is not read, there being no definite height above a flow block to resolve it against.
